🎨 Tailwind CSS v4

重点学

是什么

Tailwind 是「原子化」CSS 框架：不写自定义 class，直接在 HTML 里用 class="bg-primary text-white p-4" 这种工具类拼出样式。v4 是 2024 发布的大版本，配置大幅简化。

为什么这个项目要用它

本项目 src/app/globals.css 第一行 @import "tailwindcss"; 就是 v4 的引入方式。所有组件（如 Sidebar、Card）的样式都是 Tailwind 类名拼出来的。

项目里的实际位置：

  • postcss.config.mjs — PostCSS 插件配置（仅 4 行）
  • src/app/globals.css — Tailwind 入口 + 主题变量定义
  • tailwindcss + @tailwindcss/postcss（package.json）

核心概念

1. 工具类直接写在 className

// src/components/sidebar.tsx 摘录
<aside className="w-60 border-r border-border bg-card flex flex-col h-screen sticky top-0">
  ...
</aside>

每个 w-60 / border-r / bg-card 都是一个工具类，最终编译成普通 CSS。

2. v4 重大变更：CSS-first 配置

v4 抛弃了 tailwind.config.js。主题色、变量直接在 CSS 文件里用 @theme 声明：

// src/app/globals.css 摘录
:root {
  --primary: #C4654A;
  --background: #FAF8F5;
}

// .dark 覆盖
.dark {
  --primary: #D4765E;
  --background: #1A1614;
}

@theme inline {
  --color-primary: var(--primary);
  --color-background: var(--background);
}

这样 bg-primary 就直接用 var(--primary)。

3. @layer base 应用全局样式

@layer base {
  * { @apply border-border outline-ring/50; }
  body { @apply bg-background text-foreground; }
}

4. 深浅色模式

v4 用 @custom-variant dark，搭配 .dark 类或系统偏好：

@custom-variant dark (&:is(.dark *));

最小可运行示例

// 一个 Tailwind v4 按钮
<button className="bg-primary text-primary-foreground px-4 py-2 rounded-md hover:bg-primary/80">
  点击
</button>
