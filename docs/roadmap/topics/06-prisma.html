🗄️ Prisma + better-sqlite3

已知

是什么

Prisma 是 TypeScript 优先的 ORM：用 schema.prisma 定义模型，自动生成类型安全的客户端。本项目用 SQLite（prisma/dev.db）+ Prisma 7 + better-sqlite3 驱动。

为什么这个项目要用它

数据库 schema 跟 TypeScript 类型严格对齐，重构 schema 后所有调用点编译报错，零运行时类型错误。SQLite 适合单机 / 个人项目，零运维。

项目里的实际位置：

  • prisma/schema.prisma — 数据模型定义（7 张表）
  • src/lib/prisma.ts — PrismaClient 单例 + better-sqlite3 适配器
  • src/generated/prisma/ — 自动生成的客户端（gitignored）
  • prisma/migrations/ — 数据库迁移历史
  • prisma/seed.ts — 种子数据脚本

核心概念

1. schema.prisma

// prisma/schema.prisma 摘录
datasource db {
  provider = "sqlite"
}

model HotTopic {
  id         String   @id @default(cuid())
  title      String
  source     String   @default("manual")
  content    String   @default("")
  created_at DateTime @default(now())
  entries    ContentEntry[]
}

2. 单例 + Adapter 模式

PrismaClient 在 dev 热重载时会反复实例化，所以用 globalThis 缓存。v7 强制走 Adapter：

// src/lib/prisma.ts
import { PrismaClient } from "@/generated/prisma/client";
import { PrismaBetterSqlite3 } from "@prisma/adapter-better-sqlite3";

const globalForPrisma = globalThis as unknown { prisma: PrismaClient };

function createPrismaClient() {
  const adapter = new PrismaBetterSqlite3({
    url: process.env.DATABASE_URL || "file:./prisma/dev.db",
  });
  return new PrismaClient({ adapter });
}

export const prisma = globalForPrisma.prisma || createPrismaClient();
if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;

3. 常用查询

// 查全部
const topics = await prisma.hotTopic.findMany();

// 条件 + 关联
const entry = await prisma.contentEntry.findUnique({
  where: { id },
  include: { platforms: true, hot_topic: true },
});

// 创建
await prisma.hotTopic.create({ data: { title, source: "manual" } });

4. 迁移与生成

# schema 改完后
pnpm prisma migrate dev      # 生成迁移文件 + 应用 + 重生客户端

# 仅重生客户端（schema 没改但 import 报错）
pnpm prisma generate

最小可运行示例

完整 API Route 调用 Prisma：

// src/app/api/hot-topics/route.ts
import { NextRequest, NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";

export async function GET(request: NextRequest) {
  const hotTopics = await prisma.hotTopic.findMany({ orderBy: { created_at: "desc" } });
  return NextResponse.json({ hotTopics });
}
