🤖 Anthropic SDK

已知

是什么

官方 @anthropic-ai/sdk（Node 版）封装了 Claude Messages API。本项目用它把热点 + 用户评论 + 平台规则，组装成 prompt 一次发到 Claude，生成各平台适配文案。

为什么这个项目要用它

项目核心价值之一就是「一处写作、多平台发布」。AI 生成模块是核心环节：src/lib/ai.ts。支持自定义 ANTHROPIC_BASE_URL（用于代理 / 测试）。

项目里的实际位置：

  • src/lib/ai.ts — Anthropic 客户端 + 平台化生成函数
  • .env — ANTHROPIC_API_KEY / ANTHROPIC_BASE_URL / ANTHROPIC_MODEL
  • src/app/api/generate/route.ts（如果存在）— 暴露给前端的 HTTP 接口

核心概念

1. 客户端初始化

// src/lib/ai.ts 摘录
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
  baseURL: process.env.ANTHROPIC_BASE_URL,
});

2. Messages API 调用

const message = await anthropic.messages.create({
  model: process.env.ANTHROPIC_MODEL || "claude-3-5-sonnet-20241022",
  max_tokens: 4096,
  system: systemPrompt,
  messages: [{ role: "user", content: userMessage }],
});

const textBlock = message.content.find(b => b.type === "text");
return textBlock ? textBlock.text : "";

响应是 content 数组，每项带 type（"text" 或 "tool_use"）。本项目只用 text。

3. Prompt 拼装：system + user

buildPrompt 把平台规则（来自 PlatformRule 表）拼进 system prompt：

const systemPrompt = `你是一个专业的内容创作者 ...
当前平台：${platformRule.label}
平台规则：
- 风格：${platformRule.style}
- 结构：${platformRule.structure}
- 约束：${JSON.parse(platformRule.constraints).maxLength} 字以内`;

4. 批量并行生成

多平台时用 Promise.all 并发请求，单平台失败不影响其他平台但统一抛错：

export async function generateForAllPlatforms(...) {
  const results = await Promise.all(
    platformRules.map(async (rule) => {
      try {
        const content = await generateForPlatform(hotTopic, userComment, rule);
        return { platform: rule.platform, content };
      } catch (err) {
        throw new Error(`生成 ${rule.label} 内容失败: ${err.message}`);
      }
    })
  );
  return results.reduce((acc, r) => ({ ...acc, [r.platform]: r.content }), {});
}

5. 环境变量

# .env
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_BASE_URL=https://api.anthropic.com   # 可选，自定义代理
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022      # 可选，默认模型

最小可运行示例

import Anthropic from "@anthropic-ai/sdk";
const client = new Anthropic();

const msg = await client.messages.create({
  model: "claude-3-5-sonnet-20241022",
  max_tokens: 1024,
  messages: [{ role: "user", content: "用一句话介绍 TypeScript" }],
});
console.log(msg.content[0].text);
