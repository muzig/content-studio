🧩 shadcn/ui

重点学

是什么

shadcn/ui 不是一个 npm 包，而是一套「复制源码到项目里」的组件库。你想要哪个组件，就 npx shadcn add button 把源码贴进 src/components/ui/。完全可改、可拥有。

为什么这个项目要用它

本项目用 shadcn 提供 9 个原子组件（Button / Card / Dialog / Input / Select / Tabs / Textarea / Tooltip / Badge）。底层是 Base UI（@base-ui/react）+ Tailwind + class-variance-authority。

项目里的实际位置：

  • src/components/ui/ — 9 个手写组件文件
  • components.json — shadcn 配置（风格 base-nova、中性色）
  • src/lib/utils.ts — cn() 工具函数

核心概念

1. CVA（Class Variance Authority）

用对象定义 variant（如 primary/ghost/outline），运行时根据 props 拼 class：

// src/components/ui/button.tsx 摘录
import { cva } from "class-variance-authority";

const buttonVariants = cva(
  "rounded-lg border ...",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground",
        outline: "border-border bg-background hover:bg-muted",
        ghost: "hover:bg-muted",
      },
      size: {
        default: "h-8 px-2.5",
        sm: "h-7 text-xs",
        lg: "h-9 px-2.5",
      },
    },
    defaultVariants: { variant: "default", size: "default" },
  }
);

2. cn() = clsx + tailwind-merge

// src/lib/utils.ts
import { clsx } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs) {
  return twMerge(clsx(inputs));
}

cn("p-2", cond && "p-4") 会智能合并 Tailwind 类，后写的覆盖前写的（twMerge 解析冲突）。

3. Base UI 提供无样式原语

@base-ui/react/button 等组件只管行为（a11y、键盘、焦点），样式完全自己写。shadcn 在上面包一层 Tailwind。

4. 添加新组件

# 命令行（项目已配 components.json）
npx shadcn@latest add dialog

# 源码会贴到 src/components/ui/dialog.tsx

最小可运行示例

import { Button } from "@/components/ui/button";

<Button variant="outline" size="sm">取消</Button>
<Button>确认</Button>
