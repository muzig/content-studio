⚛️ React 19

重点学

是什么

React 是 Facebook 开源的 UI 库，用「组件」描述界面、用「状态」驱动更新。本项目用 React 19.2（package.json）。Next.js 的页面和组件本质上都是 React 组件。

为什么这个项目要用它

所有交互 UI 都是 React 组件：Sidebar、Card、Dialog、Button 等。Next.js App Router 只是路由层，渲染出来的还是 React。

项目里的实际位置：

  • src/components/ — 所有 React 组件
  • src/components/ui/ — shadcn 提供的原子组件（Button、Dialog…）

核心概念

1. 组件 = 函数

一个 React 组件就是一个返回 JSX 的函数。大写开头、返回 HTML-like 结构。

function Greeting({ name }: { name: string }) {
  return <h1>Hello, {name}</h1>;
}

// 使用
<Greeting name="World" />

2. JSX = HTML + {} 表达式

JSX 是 JavaScript 的语法扩展，{} 里能写任意 JS 表达式。

const items = ["a", "b", "c"];
return (
  <ul>
    {items.map(item => <li key={item}>{item}</li)}
  </ul>
);

3. Hook：useState / useEffect

Hook 是 React 函数组件里的「钩子」，让你接入状态和生命周期。本项目常用的：

"use client";
import { useState, useEffect } from "react";

function Counter() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    document.title = `计数：${count}`;
  }, [count]);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}

4. "use client" 指令

Next.js 默认服务端渲染。要用 useState / onClick / 浏览器 API，必须在文件顶部加 "use client"，告诉 Next.js 把这组件发到浏览器执行。

经验法则：尽量保持服务端组件，只把需要交互的子组件标 Client。本项目 sidebar.tsx / hot-topic-form.tsx 等是 Client。

最小可运行示例

改 src/app/hello/page.tsx 为交互组件：

"use client";
import { useState } from "react";

export default function Hello() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + 1)}>点了 {n} 次</button>;
}
