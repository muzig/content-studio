🚀 Next.js App Router

重点学

是什么

Next.js 是一个基于 React 的全栈框架。本项目使用 App Router（Next.js 13+ 引入的现代路由系统），通过文件目录结构定义路由与服务端行为。

为什么这个项目要用它

App Router 是项目的骨架：每个页面是一个文件、每个 API 是一段 Route Handler、共享布局放在 layout.tsx。本项目用 Next.js 16（package.json）。

项目里的实际位置：

  • src/app/layout.tsx — 全局布局（字体、Sidebar、TooltipProvider）
  • src/app/page.tsx — 根路由，重定向到当天 daily 页
  • src/app/daily/[date]/page.tsx — 动态路由示例
  • src/app/api/entries/[id]/route.ts — API Route Handler

核心概念

1. 文件系统即路由

src/app/ 下的每个文件夹 = 一个 URL 段。page.tsx 是页面、layout.tsx 是布局、route.ts 是 API。文件名是约定，不可改。

// src/app/page.tsx — 根路由 / 
import { redirect } from "next/navigation";

export default function Home() {
  const d = new Date();
  const today = `${d.getFullYear()}-${...}`;
  redirect(`/daily/${today}`);
}

2. Server Component vs Client Component

默认是 Server Component（在服务端渲染、不发到浏览器）。需要交互（onClick、useState）才加 "use client" 指令。本项目 Sidebar 是 Client（要 usePathname），页面默认是 Server。

// src/components/sidebar.tsx — 客户端组件
"use client";

import { usePathname } from "next/navigation";

export function Sidebar() {
  const pathname = usePathname();
  // ... 渲染导航 ...
}

3. 动态路由 [param] — Client 端 useParams

文件夹名用 [xxx] 表示动态段。params.xxx 在 Server Component 中通过 props 访问；在 Client Component 中用 useParams() 钩子访问。本项目 daily/[date]/page.tsx 是 Client Component（需要交互式日期切换）。

// src/app/daily/[date]/page.tsx
"use client";

import { useState, useEffect, useCallback } from "react";
import { useParams, useRouter } from "next/navigation";

export default function DailyPage() {
  const params = useParams();
  const router = useRouter();
  const date = params.date as string;

  const [entries, setEntries] = useState<Entry[]>([]);
  const [loading, setLoading] = useState(true);

  const fetchEntries = useCallback(async () => {
    const res = await fetch(`/api/daily/${date}`);
    const data = await res.json();
    setEntries(data.entries || []);
    setLoading(false);
  }, [date]);

  useEffect(() => { fetchEntries(); }, [fetchEntries]);
  // ...
}

4. Route Handler（API）

route.ts 导出 GET / POST 等方法函数，对应 HTTP 动词。推荐用 NextRequest / NextResponse 以便访问请求头、构造带状态码的响应。

// src/app/api/entries/[id]/route.ts
import { NextRequest, NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";

export async function GET(
  request: NextRequest,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;

  const entry = await prisma.contentEntry.findUnique({
    where: { id },
    include: { hot_topic: true, platforms: true },
  });

  if (!entry) {
    return NextResponse.json({ error: "Entry not found" }, { status: 404 });
  }

  return NextResponse.json({ entry });
}

最小可运行示例

创建一个最简单的页面 src/app/hello/page.tsx：

export default function Hello() {
  return <h1>Hello</h1>;
}

访问 http://localhost:3000/hello 即可看到。
