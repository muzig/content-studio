# Roadmap 文档站点 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `docs/roadmap/` 下构建一个纯静态 HTML 文档站点，讲解本项目所用技术栈；通过 `pnpm roadmap`（基于 `serve` 包）在 `http://localhost:3001` 启动本地访问。

**Architecture:** 11 个静态文件（1 个 index + 8 个 topic + 1 个 template + 1 个 css）。零构建、零运行时 JS、CSS 变量跟系统主题。无后端、无数据库。`serve` 仅作为静态文件服务器。

**Tech Stack:** 静态 HTML5 + CSS（自定义变量 + `prefers-color-scheme`）、Node 包 `serve ^14.2.4`（devDependency）。

## Global Constraints

- 所有文件路径相对仓库根
- 所有 HTML 必须 UTF-8 编码、`<html lang="zh-CN">`
- 代码块高亮仅三档：关键字 / 字符串 / 注释，手写 CSS
- CSS 变量名必须与 `src/app/globals.css` 中定义的一致（`--background` / `--foreground` / `--primary` / `--card` / `--border` / `--muted` / `--muted-foreground` / `--secondary` / `--accent`）
- 深色模式用 `@media (prefers-color-scheme: dark)`，变量值与 `globals.css` 中 `.dark` 块一致
- 字体栈：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`，代码块用 `ui-monospace, "SF Mono", Menlo, Consolas, monospace`
- 所有外链必须 `target="_blank" rel="noopener noreferrer"`
- 中文与英文/数字之间保留一个空格

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Next.js App Router — Content Studio 技术路线图</title>
  <link rel="stylesheet" href="../assets/style.css">
</head>
<body>
  <div class="container">
    <p><a href="../index.html">← 返回路线图</a></p>
    <h1>🚀 Next.js App Router</h1>
    <span class="badge badge-yellow">重点学</span>

    <h2>是什么</h2>
    <p>Next.js 是一个基于 React 的全栈框架。本项目使用 <strong>App Router</strong>（Next.js 13+ 引入的现代路由系统），通过文件目录结构定义路由与服务端行为。</p>

    <h2>为什么这个项目要用它</h2>
    <p>App Router 是项目的骨架：每个页面是一个文件、每个 API 是一段 Route Handler、共享布局放在 <code>layout.tsx</code>。本项目用 Next.js 16（package.json）。</p>
    <p>项目里的实际位置：</p>
    <ul>
      <li><code>src/app/layout.tsx</code> — 全局布局（字体、Sidebar、TooltipProvider）</li>
      <li><code>src/app/page.tsx</code> — 根路由，重定向到当天 daily 页</li>
      <li><code>src/app/daily/[date]/page.tsx</code> — 动态路由示例</li>
      <li><code>src/app/api/entries/[id]/route.ts</code> — API Route Handler</li>
    </ul>

    <h2>核心概念</h2>

    <h3>1. 文件系统即路由</h3>
    <p><code>src/app/</code> 下的每个文件夹 = 一个 URL 段。<code>page.tsx</code> 是页面、<code>layout.tsx</code> 是布局、<code>route.ts</code> 是 API。文件名是约定，不可改。</p>
    <pre class="code-block"><code><span class="com">// src/app/page.tsx — 根路由 / </span>
<span class="kw">import</span> { redirect } <span class="kw">from</span> <span class="str">"next/navigation"</span>;

<span class="kw">export default function</span> Home() {
  <span class="kw">const</span> d = <span class="kw">new</span> Date();
  <span class="kw">const</span> today = <span class="str">`${d.getFullYear()}-${...}`</span>;
  redirect(<span class="str">`/daily/${today}`</span>);
}</code></pre>

    <h3>2. Server Component vs Client Component</h3>
    <p>默认是 Server Component（在服务端渲染、不发到浏览器）。需要交互（onClick、useState）才加 <code>"use client"</code> 指令。本项目 <code>Sidebar</code> 是 Client（要 <code>usePathname</code>），页面默认是 Server。</p>
    <pre class="code-block"><code><span class="com">// src/components/sidebar.tsx — 客户端组件</span>
<span class="str">"use client"</span>;

<span class="kw">import</span> { usePathname } <span class="kw">from</span> <span class="str">"next/navigation"</span>;

<span class="kw">export function</span> Sidebar() {
  <span class="kw">const</span> pathname = usePathname();
  <span class="com">// ... 渲染导航 ...</span>
}</code></pre>

    <h3>3. 动态路由 [param]</h3>
    <p>文件夹名用 <code>[xxx]</code> 表示动态段，通过 <code>params.xxx</code> 访问。</p>
    <pre class="code-block"><code><span class="com">// src/app/daily/[date]/page.tsx</span>
<span class="kw">export default async function</span> DailyPage({
  params,
}: {
  params: <span class="kw">Promise</span>&lt;{ date: <span class="kw">string</span> }&gt;;
}) {
  <span class="kw">const</span> { date } = <span class="kw">await</span> params;
  <span class="com">// 用 date 查 DailyNote ...</span>
}</code></pre>

    <h3>4. Route Handler（API）</h3>
    <p><code>route.ts</code> 导出 <code>GET</code> / <code>POST</code> 等方法函数，对应 HTTP 动词。</p>
    <pre class="code-block"><code><span class="com">// src/app/api/entries/[id]/route.ts</span>
<span class="kw">import</span> { prisma } <span class="kw">from</span> <span class="str">"@/lib/prisma"</span>;

<span class="kw">export async function</span> GET(
  _: Request,
  { params }: { params: <span class="kw">Promise</span>&lt;{ id: <span class="str">string</span> }&gt; }
) {
  <span class="kw">const</span> { id } = <span class="kw">await</span> params;
  <span class="kw">const</span> entry = <span class="kw">await</span> prisma.contentEntry.findUnique({ where: { id } });
  <span class="kw">return</span> Response.json(entry);
}</code></pre>

    <h2>最小可运行示例</h2>
    <p>创建一个最简单的页面 <code>src/app/hello/page.tsx</code>：</p>
    <pre class="code-block"><code><span class="kw">export default function</span> Hello() {
  <span class="kw">return</span> &lt;<span class="kw">h1</span>&gt;Hello&lt;/<span class="kw">h1</span>&gt;;
}</code></pre>
    <p>访问 <code>http://localhost:3000/hello</code> 即可看到。</p>

    <h2>下一步学什么</h2>
    <ul>
      <li>React 基础 → <a href="./02-react.html">02 · React 19</a></li>
      <li>TypeScript 路径别名 → <a href="./03-typescript.html">03 · TypeScript</a></li>
      <li>官方文档：<a href="https://nextjs.org/docs/app" target="_blank" rel="noopener noreferrer">Next.js App Router 文档</a></li>
    </ul>

    <p class="back-link"><a href="../index.html">🔙 返回路线图</a></p>
  </div>
</body>
</html>
```

```html
    <pre class="code-block"><code><span class="kw">function</span> Greeting({ name }: { name: <span class="kw">string</span> }) {
  <span class="kw">return</span> &lt;<span class="kw">h1</span>&gt;Hello, {name}&lt;/<span class="kw">h1</span>&gt;;
}

<span class="com">// 使用</span>
&lt;<span class="kw">Greeting</span> name=<span class="str">"World"</span> /&gt;</code></pre>

    <h3>2. JSX = HTML + {} 表达式</h3>
    <p>JSX 是 JavaScript 的语法扩展，<code>{}</code> 里能写任意 JS 表达式。</p>
    <pre class="code-block"><code><span class="kw">const</span> items = [<span class="str">"a"</span>, <span class="str">"b"</span>, <span class="str">"c"</span>];
<span class="kw">return</span> (
  &lt;<span class="kw">ul</span>&gt;
    {items.map(item =&gt; &lt;<span class="kw">li</span> key={item}&gt;{item}&lt;/<span class="kw">li</span>&gt;)}
  &lt;/<span class="kw">ul</span>&gt;
);</code></pre>

    <h3>3. Hook：useState / useEffect</h3>
    <p>Hook 是 React 函数组件里的「钩子」，让你接入状态和生命周期。本项目常用的：</p>
    <pre class="code-block"><code><span class="str">"use client"</span>;
<span class="kw">import</span> { useState, useEffect } <span class="kw">from</span> <span class="str">"react"</span>;

<span class="kw">function</span> Counter() {
  <span class="kw">const</span> [count, setCount] = useState(<span class="str">0</span>);
  useEffect(() =&gt; {
    document.title = <span class="str">`计数：${count}`</span>;
  }, [count]);
  <span class="kw">return</span> &lt;<span class="kw">button</span> onClick={() =&gt; setCount(count + <span class="str">1</span>)}&gt;{count}&lt;/<span class="kw">button</span>&gt;;
}</code></pre>

    <p>Next.js 默认服务端渲染。要用 <code>useState</code> / <code>onClick</code> / 浏览器 API，必须在文件顶部加 <code>"use client"</code>，告诉 Next.js 把这组件发到浏览器执行。</p>
    <div class="note">
      <p><strong>经验法则：</strong>尽量保持服务端组件，只把需要交互的子组件标 Client。本项目 <code>sidebar.tsx</code> / <code>hot-topic-form.tsx</code> 等是 Client。</p>
```
